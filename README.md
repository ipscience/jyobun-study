# 条文スタディ

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Chrome Web Store](https://img.shields.io/badge/Chrome-Extension-green?logo=googlechrome)](https://chrome.google.com/webstore)
[![Manifest V3](https://img.shields.io/badge/Manifest-V3-orange)](https://developer.chrome.com/docs/extensions/mv3/)

**条文スタディ**は、Webページ上の法令参照（「特許法第29条」など）を自動検出し、[e-Gov法令検索API](https://laws.e-gov.go.jp/)から条文を取得してポップアップ表示するChrome拡張機能です。

法律の学習や実務での条文確認を効率化します。穴埋め学習、条文ブラウジング、相互参照ナビゲーションなど、条文学習に役立つ機能を備えています。

---

## 特徴

### 基本機能
- **自動検出**: Webページ内の法令参照を自動的に検出してハイライト表示
- **ポップアップ表示**: マウスオーバーで条文をその場に表示（ページ移動不要）
- **検索モーダル**: ページ内にドラッグ移動・リサイズ可能なフローティングウィンドウで条文検索
- **条文ブラウジング**: 法令の全条文一覧を表示し、前条/次条ナビゲーションで閲覧
- **穴埋め学習**: 主語・述語・鉤括弧内用語・除外条件の4パターンで暗記学習
- **相互参照リンク**: 条文内の「前条」「次条」「第○条」等をクリック可能なリンクに変換
- **41法令対応**: 知財・民事・刑事・行政・労働・経済など幅広い法分野をカバー

### アクセス方法
- **フローティングボタン**: 画面右上に常時表示（ドラッグ移動・位置保存対応）
- **右クリックメニュー**: テキスト選択して条文を検索（PDF対応）
- **ツールバーポップアップ**: 拡張機能アイコンから直接検索
- **検索ページ**: 新しいタブで独立した検索ページを表示

### 学習・閲覧支援
- **項・号ハイライト**: 参照先の項・号を黄色背景で強調表示
- **括弧内ハイライト**: 定義部分の括弧書きを灰色背景で視覚的に区別
- **履歴・戻るボタン**: 条文間を辿った履歴を記録、ワンクリックで戻れる
- **カテゴリタブ**: 法令を6カテゴリに分類し、素早くアクセス

### パフォーマンス・プライバシー
- **3層キャッシュ**: メモリ（LRU 100件）+ ローカルストレージ（7日TTL）+ パース済みXML DOM
- **モックデータ**: API接続不可時も主要条文を表示するフォールバック機能
- **プライバシー重視**: e-Gov API以外への外部通信なし、個人情報の収集・送信なし

## 使い方

### 方法1: フローティングボタン（おすすめ）

画面右上に常時表示されるボタンから、ワンクリックで検索モーダルを開けます。

| 操作 | 動作 |
|------|------|
| クリック | 検索モーダルを開く |
| テキスト選択してクリック | 選択テキストで自動検索 |
| ドラッグ | ボタン位置を移動（位置は自動保存） |

> ボタンの表示/非表示はツールバーポップアップのトグルスイッチで切り替えできます。

### 方法2: 自動検出（Webページ）

1. 拡張機能をインストールして任意のWebページを開く
2. ページ内の法令参照が **青い点線** でハイライトされる
3. ハイライト部分にマウスを合わせると条文がポップアップ表示

**認識例：**
- `特許法第29条` ✅
- `特許法29条`（「第」省略） ✅
- `特 許 法 第 29 条`（空白あり） ✅
- `特許法第二十九条`（漢数字） ✅
- `民法709条`、`著作権法2条1項` ✅
- `特29条`（略称） ✅

### 方法3: 右クリックメニュー

| 状態 | メニュー項目 |
|------|-------------|
| テキスト選択あり | 「"○○" を条文スタディで検索」 |
| テキスト選択なし | 「条文スタディを開く」 |

> 💡 **PDF対応**: PDFではフローティングボタンが使えないため、右クリックメニューをご利用ください。

### 方法4: ツールバーアイコン

1. ツールバーの拡張アイコン（📚）をクリック
2. 検索ボックスに法令参照を入力（クイックリンクからも選択可能）
3. Enter キーまたは「検索」ボタンで条文表示
4. 「新しいタブで開く」ボタンで検索ページに切り替え可能

## 検索モーダル

フローティングボタンのクリックで開く、ページ内のリッチな検索ウィンドウです。

| 機能 | 説明 |
|------|------|
| **ドラッグ移動** | ヘッダーをドラッグしてウィンドウ位置を変更 |
| **リサイズ** | 8方向のハンドルでウィンドウサイズを調整 |
| **最小化** | 畳むボタンでヘッダーのみにコンパクト化 |
| **カテゴリタブ** | 法令を基本法・知財・登記・行政・商取引・その他の6カテゴリに分類 |
| **条文一覧** | 法令ボタンをクリックすると全条文をドロップダウンで一覧表示 |
| **前条/次条** | 条文表示時に隣の条文への移動ボタン |
| **一覧プルダウン** | 表示中の法令の全条文リスト（現在の条文をハイライト＆自動スクロール） |
| **法令選択** | 条番号のみの入力に対してカテゴリ分けされた法令選択ボタンを表示 |

## 条文間ナビゲーション

ポップアップ・検索モーダル内で条文の相互参照をクリック可能なリンクに変換します。

### 同一法令内の参照
- `第○条`、`第○条の○` → 対象条文にジャンプ
- `前条`、`次条`、`同条` → 相対位置の条文を自動解決
- `前項`、`次項`、`同項` → 相対位置の項を自動解決
- `第○項`、`第○号` → 文脈から参照先の条文を推定してリンク

### 他法令への参照
- 条文内の他の法令への参照（例：「民法第709条」）は、e-Gov法令検索への外部リンクとして表示

### 条約参照の除外
パリ条約・特許協力条約・マドリッド議定書等の条約への参照は、国内法と誤認されないようリンク化の対象外にしています。

## 穴埋め学習

条文表示時に「穴埋め」ボタンをクリックすると、以下の4パターンで重要箇所を隠します。

| パターン | 内容 | 例 |
|----------|------|-----|
| **主語** | 各文の「〜は」の主語部分 | ＿＿＿は、…することができる |
| **鉤括弧内** | 定義語等の「」内の用語 | 「＿＿＿」という |
| **除外条件** | （○○を除く。）形式 | （＿＿＿を除く。） |
| **末尾述語** | しなければならない、できる等 | …＿＿＿ |

穴埋め箇所をクリックすると答えが表示されます。

## 設定

設定ページ（`chrome://extensions` → 条文スタディ →「オプション」）から以下を変更できます。

| 設定項目 | 説明 |
|----------|------|
| **拡張機能の有効/無効** | 全サイトでの条文検出をオフにする |
| **除外サイト** | 条文検出を無効にするドメインを指定（ワイルドカード `*` 対応） |

フローティングボタンの表示/非表示は、ツールバーポップアップのトグルスイッチから切り替えられます。

## 技術仕様

| 項目 | 内容 |
|------|------|
| マニフェストバージョン | Manifest V3 |
| 対応ブラウザ | Google Chrome（最新版推奨） |
| API | [e-Gov法令検索API](https://laws.e-gov.go.jp/api/1/) |
| キャッシュ | 3層（メモリLRU 100件 + chrome.storage.local 7日TTL + パース済みXML DOM） |
| セキュリティ | HTMLサニタイズ（許可リスト方式）、XSSエスケープ |
| 外部ライブラリ | なし（Vanilla JavaScript） |

### ファイル構成

```
chrome_extension/
├── manifest.json       # 拡張機能マニフェスト（Manifest V3）
├── content.js          # メインスクリプト（検出・ポップアップ・モーダル・フローティングボタン）
├── law-data.js         # 法令データ定義（法令ID・略称・条文数）
├── cloze.js            # 穴埋め学習機能
├── styles.css          # コンテンツスクリプト用スタイル
├── background.js       # サービスワーカー（コンテキストメニュー）
├── popup.html/js       # ツールバーポップアップ
├── search.html/js      # 独立検索ページ
├── options.html/js     # 設定ページ
└── icon*.png           # アイコン画像（16/48/128px）
```

## 権限について

この拡張機能が必要とする権限と、その理由を説明します。

| 権限 | 用途 |
|------|------|
| `<all_urls>` | 任意のWebページで法令参照を検出・表示するため |
| `https://laws.e-gov.go.jp/*` | e-Gov法令検索APIから条文データを取得するため |
| `storage` | ユーザー設定（フローティングボタン位置、除外サイトなど）をローカルに保存するため |
| `contextMenus` | 右クリックメニューから条文を検索するため |
| `tabs` | 検索結果を新しいタブで開くため |

> ⚠️ 収集したデータを外部サーバーに送信することは**一切ありません**。

## プライバシーポリシー

- **個人情報を収集しません**
- 閲覧履歴やユーザーデータを外部サーバーに送信しません
- 条文データ取得のため、[e-Gov法令検索API](https://laws.e-gov.go.jp/)にのみアクセスします
- すべての処理はローカル（ブラウザ内）で完結します

詳細は [プライバシーポリシー](chrome_webstore/privacy_policy.md) をご覧ください。

## 既知の制限事項

| 制限 | 説明 | 回避策 |
|------|------|--------|
| PDF対応 | Chromeの制限により、PDF内ではフローティングボタン・自動検出が動作しません | 右クリックメニューを使用 |
| API接続 | 一部の環境でe-Gov APIへのアクセスが制限される場合があります | 内蔵のモックデータを自動的に表示 |
| オフライン | インターネット接続がない場合、条文を取得できません | — |

## よくある質問（FAQ）

<details>
<summary><b>Q: 条文が表示されません</b></summary>

以下を確認してください：
1. インターネットに接続されていますか？
2. [e-Gov法令検索](https://laws.e-gov.go.jp/)にアクセスできますか？
3. 拡張機能が有効になっていますか？（`chrome://extensions` で確認）
4. 設定ページで拡張機能が「有効」になっていますか？
5. 該当サイトが除外サイトに登録されていませんか？
</details>

<details>
<summary><b>Q: 特定の法令を追加してほしい</b></summary>

[Issues](https://github.com/ipscience/jyobun-study/issues) から機能リクエストをお送りください。
</details>

<details>
<summary><b>Q: PDFで使えません</b></summary>

PDFではChromeの制限により自動検出が動作しません。テキストを選択して右クリックメニューから検索してください。
</details>

<details>
<summary><b>Q: フローティングボタンが邪魔です</b></summary>

ツールバーの拡張機能アイコンをクリックし、「📚 検索ボタンを表示」のトグルをオフにしてください。
</details>

<details>
<summary><b>Q: 特定のサイトで無効にしたい</b></summary>

設定ページ（`chrome://extensions` → 条文スタディ → オプション）から除外サイトを登録できます。ワイルドカード（`*`）にも対応しています。
</details>
