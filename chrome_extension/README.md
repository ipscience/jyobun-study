# 条文スタディ Chrome拡張機能

Webページ上の法令参照（「特許法第1条」など）にマウスカーソルを合わせると、
e-Gov法令検索から条文を取得してポップアップ表示するChrome拡張機能です。

## スクリーンショット

### ポップアップ表示
![ポップアップ表示](../chrome_webstore/screenshots/screenshot_1.png)

Webページ上の法令参照（青い点線）にマウスを合わせると、条文がポップアップ表示されます。

### 穴埋め学習機能
![穴埋め学習機能](../chrome_webstore/screenshots/screenshot_2.png)

「穴埋め」ボタンをクリックすると、主語・述語・重要用語が隠され、クリックで答えを確認できます。

### 検索ページ
![検索ページ](../chrome_webstore/screenshots/screenshot_3.png)

フローティングボタンや右クリックメニューから検索ページを開き、任意の法令条文を検索できます。

## インストール方法

### 1. アイコンファイルの準備

SVGファイルをPNG形式に変換する必要があります。
オンラインツール（例：https://svgtopng.com/）を使って：
- `icon48.svg` → `icon48.png` (48x48)
- `icon128.svg` → `icon128.png` (128x128)

または、以下のPythonスクリプトで変換：

```python
# pip install cairosvg
import cairosvg

cairosvg.svg2png(url='icon48.svg', write_to='icon48.png', output_width=48, output_height=48)
cairosvg.svg2png(url='icon128.svg', write_to='icon128.png', output_width=128, output_height=128)
```

### 2. Chromeに拡張機能をインストール

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `chrome_extension` フォルダを選択

## 使い方

### 方法1: フローティングボタン（おすすめ）

**画面右下に常時表示されるボタンです。ワンクリックで検索ページが開きます。**

1. 画面右下の 📚 ボタンをクリック
2. 検索ボックスに法令参照を入力（例：「特許法29条」）
3. Enterキーで条文が表示される

※ テキストを選択した状態でボタンをクリックすると、選択テキストで自動検索します。
※ ボタンをダブルクリックすると小さくなります（邪魔な場合に）。

### 方法2: 自動検出（Webページ）

1. 拡張機能をインストール後、任意のWebページを開く
2. ページ内の法令参照（例：「特許法第1条」）が青い点線付きで表示される
3. その部分にマウスカーソルを合わせると条文がポップアップ表示される

### 方法3: 右クリックメニュー（PDF対応）

**PDFでも使えます。**

- テキスト選択あり → 右クリック → 「"○○"を条文スタディで検索」
- テキスト選択なし → 右クリック → 「条文スタディを開く」

※ 空白が入っていても認識します（例：「特許法第 29 条」→ OK）

### 方法4: ツールバーアイコン

1. ツールバーの拡張アイコン（📚）をクリック
2. 検索ボックスに法令参照を入力
3. Enterキーまたは「検索」ボタンで条文表示

## 対応法令

- 特許法、民法、著作権法、商標法、意匠法、実用新案法
- 会社法、刑法、民事訴訟法、刑事訴訟法
- 労働基準法、独占禁止法、不正競争防止法
- 個人情報保護法、消費者契約法
- 行政手続法、行政事件訴訟法、国家賠償法
- 憲法、破産法、金融商品取引法、景品表示法
- 製造物責任法、電子署名法、種苗法、半導体集積回路法

## 注意事項

- PDFはChromeの制限によりフローティングボタン・自動検出が使えません。右クリックメニューをご利用ください。
- e-Gov法令APIにはCORS制限があるため、直接APIを呼び出せない場合があります
- その場合は内蔵のモックデータが表示されます
- ポップアップ下部のリンクからe-Gov法令検索の全文を確認できます

## ファイル構成

```

├── manifest.json    # 拡張機能の設定
├── law-data.js      # 法令ID・略称の定数データ

├── content.js       # メインのJavaScriptコード
├── search.js        # 検索ページ用スクリプト

├── icon16.png       # アイコン（16x16）
├── icon48.png       # アイコン（48x48）
├── icon128.png      # アイコン（128x128）
└── README.md        # このファイル
```

## 権限について

この拡張機能は以下の権限を使用します：

- **すべてのサイトへのアクセス (`<all_urls>`)**: 任意のWebページ上で法令参照を検出し、条文をポップアップ表示するために必要です
- **e-Gov法令検索API (`https://laws.e-gov.go.jp/*`)**: 条文データを取得するために使用します
- **ストレージ (`storage`)**: 設定を保存するために使用します

**プライバシーについて**: この拡張機能は閲覧データを外部に送信しません。条文取得のためにe-Gov法令検索APIにのみアクセスします。
